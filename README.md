
# 🚀 ArgoCD GitOps Demo Repository

Welcome to the **ArgoCD GitOps Demo Repository**!  
This repository serves as a **comprehensive reference for deploying Kubernetes applications using ArgoCD** and GitOps principles.

It includes hands-on demos and configurations covering:

- 📦 Helm Chart Deployments
- 🔁 Kustomize Overlays
- 📝 Raw Kubernetes Manifests
- 🔐 Integration with Private Git Repositories
- 🌐 Multi-cluster Management
- 🔧 ArgoCD CLI Usage & Automation

Each use case is organized into its own folder with a dedicated `README.md` explaining how to reproduce and test that scenario.

---

## 🎯 What You’ll Learn

By exploring this repo, you’ll learn how to:

- Set up ArgoCD with different deployment strategies
- Manage environments using overlays and Helm values
- Authenticate ArgoCD with private Git repositories
- Connect and deploy to multiple Kubernetes clusters
- Use the ArgoCD CLI for automation and configuration

---

## 🚀 Getting Started

1. Clone this repository:


2. Navigate to any demo directory of interest.

3. Follow the instructions in the respective `README.md` to:

   * Install resources
   * Sync with ArgoCD
   * Observe deployment behavior in both CLI and UI
